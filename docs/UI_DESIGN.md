# UI 与交互设计

首页使用统一入口导入 HTML、ZIP 或公开 URL，支持文件选择、拖放、内置示例和最近项目。URL 模式说明静态捕获范围和本地副本边界，导入完成后显示保存的样式和图片数量以及跳过项。

桌面工作台依次呈现问题与历史、修复证据、修复助手或验证结论。问题区可按严重程度筛选，或切换到已解决记录。历史记录保留原始修复对应的版本和扫描 ID，版本恢复后仍可回看。

证据区提供三种视图：

- 视觉对比显示两次扫描的真实截图，可并排或单独查看。问题坐标来自保存的扫描，修复后的元素可按同一选择器在对应快照中重新定位。
- 代码 Diff 分别展示待审核的实际文件变化、已应用的统一补丁和缺少补丁时的空状态。
- 无障碍语义读取 Chromium 无障碍树，显示修复前后的可访问名称、角色、聚焦能力和相关状态。复测结果和 WCAG 依据在右侧关联展示。

修复确认使用原生模态对话框，默认聚焦返回审核按钮，支持 Escape。应用成功后焦点移至该问题的语义证据。页面提供跳转到主要内容、可见键盘焦点、状态提示和响应式布局。报告包括验证历史、恢复版本、人工复核和带内容说明的 ZIP 导出入口。
