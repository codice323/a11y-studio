# UI 与交互设计

浅色背景与深蓝品牌色。首页提供 HTML/ZIP 上传、拖放和三种示例；展示最近项目以及扫描、修复、验证三个步骤。工作台顶部展示项目、版本、扫描和导出；下方四项指标基于扫描记录计算。

桌面工作台采用三栏：左侧问题列表与严重程度筛选；中间原始/当前截图、问题定位高亮、源码差异；右侧用户影响、规范依据、模型或手工建议和审核操作。确认使用原生模态对话框；加载、失败、空列表与无模型配置均有提示。窄屏改为单栏。报告页展示验证日志、代码差异、人工复核和历史版本。

自身体现在语义标题、表单标签、键盘操作、可见焦点和状态消息。截图高亮依赖检测时的元素位置；页面较长时会滚动到选中元素。
