# 检测覆盖与双侧实时比较

基线是 `1109.v2` 的 `82345b0`。工作台的逐页面审计、AI 视觉、Agent、修复预览和历史截图仍按原入口使用。

## 运行时覆盖

实际注入来自 `@axe-core/playwright@4.13.0` 所依赖的 axe-core 4.13.0。仓库顶层的 axe-core 4.14.0 不代表浏览器注入版本。默认配置为 `wcag2a`、`wcag2aa`、`wcag21a`、`wcag21aa`、`wcag22a`、`wcag22aa`、`best-practice`，显式排除 `focus-order-semantics` 与 `hidden-content`。按该运行时目录读取共 98 条候选规则，其中 A/AA 标签组命中 70 条，最佳实践命中 28 条。4.13.0 目录中 `wcag22a` 无匹配规则。候选规则的数量不等于某次扫描实际执行数量，也不等于 WCAG 条款数量。

| 类别 | 实际检查和证据 | 仍需确认的范围 |
| --- | --- | --- |
| 结构与导航语义 | axe 检查语言、标题、地标、ARIA 角色与引用、表格、跳转链接。最佳实践和 WCAG 违规分开。 | 标题顺序及内容结构是否有意义，用户能否顺利完成导航。 |
| 视觉、表单和目标尺寸 | axe 自动检查支持的对比度、可访问名称、图片替代、表单标签和目标尺寸。遮挡、复杂背景等 axe 无法确定的结果保留为 incomplete。 | 可见焦点是否足够明显、文字语境、触屏使用及所有例外条件。 |
| 浏览器键盘 | 历史 V2 的实际 Tab 探查和 AX 树记录顺序、跳过、焦点样式和浏览器语义。实时会话连续三次 Tab 停留在同一焦点时列为疑似陷阱。 | 有界探查不是完整键盘路径。复合控件、循环焦点、可用的退出方式须人工复核。 |
| 动态组件 | 真正执行操作后检查弹窗焦点进入和恢复、展开状态与目标可见性、SPA 路由反馈、原生校验的附加错误关联，以及现有实时区域的变化。用户可直接对当时的 DOM 再运行 axe。 | 动态提示是否完整播报、软键盘、拖拽、定时交互及未触发状态。 |
| AI 辅助审核 | 既有语义复核、图像描述和 Agent 可以解释页面语境与修复证据。RAG 检索提供规则依据。 | AI 判断和 RAG 不增加 axe 的规则，不提升待复核结果的确定性。 |
| 媒体及人工体验 | 目录包含 `video-caption`。实时扫描记录音视频元素和声明的轨道类型、语言。 | 字幕质量、同步、音频描述、文本替代和读屏播报须人工体验。 |
| 当前不支持 | 跨源实时嵌入、第三方支付、登录态及真实业务提交。只支持预定义键盘操作和固定测试输入。 | 任意 Web 应用全流程及 WCAG 一致性认证。 |

判读零违规时，先看页面及状态是否成功扫描，再对照具体规则的 `passes`、`violations`、`incomplete`、`inapplicable`。标签未覆盖、禁用规则、最佳实践分流及未进入的状态都不应算入确定性违规。实时结果单独记录状态与版本，静态汇总继续沿用历史逐页证据。参照 [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)。

## 工作台使用方式

在主导航选择「实时浏览器」，并在顶部选择两个版本。诊断工作台和实时浏览器共用所选版本。静态项目从诊断所选页面打开实时会话，可将实时页面交回诊断。React 项目从入口加载，视图切换时继续保留已进入的动态状态。默认沿用原始版对当前版。画面是隔离 Chrome 的事件驱动远程渲染，操作会改变实际浏览器状态，异步画面可手动刷新。点击坐标只用于发起侧的 DOM 命中，重放按唯一的可访问角色和名称匹配，链接还要求同一目的地。关闭同步后可分别操作。键盘和读屏用户可用语义控件下拉框与操作按钮。

当前帧不同时，界面分别显示路由、DOM 摘要、AX 树、焦点和画面差异。找不到唯一目标、表单行为或目的地不一致、操作后出现不同弹窗或控件状态时报告失配。发起侧已执行的操作保留，可独立核对。

实时检测直接扫描当前 DOM，独立保存版本、状态、规则、网络、DOM 摘要、可访问语义及操作记录。实时扫描可以下载 JSON 或在结果报告查看。实时发现目前为审查证据；可复现的历史状态仍是原有源码修复入口。

## 隔离边界

| 导入 | 实时支持 |
| --- | --- |
| HTML | 自身资源、原生链接、details、对话框、焦点和校验。缺失关联资源可从扫描失败记录查看。 |
| ZIP | 真实归档内页面和资源、原生交互。上传脚本不执行。 |
| 受支持的 React 源码工程 | 使用项目已有的受限构建与虚拟本地站点，运行本地构建的组件与路由。 |
| URL 静态快照 | 已采集页面、资源与原生交互。原站脚本、实时服务及账号状态不可用。 |

两侧拥有独立 Chrome 实例及上下文，只访问拦截的虚拟本地地址。保留浏览器沙箱、CSP、请求预算、无外网、无下载和弹窗关闭策略。普通控件允许本地状态变化，业务类动作和外部链接阻止执行，表单只能运行浏览器原生校验。一次只打开一对会话，最长五分钟。同步范围为页面滚动，内嵌独立滚动容器、触控手势和连续视频流未覆盖。

## 本机复验

先运行 `npm run build`。运行 `A11Y_LIVE_EVIDENCE=data/live-comparison node --import tsx --test tests/live-comparison-e2e.test.ts`。测试在临时目录生成校园样例，并启动独立服务和独立数据库，并保留 Playwright 轨迹、操作记录、规则、DOM 和网络日志。
