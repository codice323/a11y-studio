# 5–8 分钟演示脚本

1. 0:00–0:40：介绍网页无障碍的真实问题、目标用户和产品目标。
2. 0:40–1:30：选择“慢绿生活”示例，展示真实扫描、严重程度和截图定位。
3. 1:30–3:30：选择表单问题，解释用户影响和 WCAG 依据；填写或调用已配置模型生成建议；查看实际代码差异，确认应用，等待复测。
4. 3:30–4:30：展示原始与当前版本、解决/残留/新增统计；再演示一个图片或按钮补丁，并说明语义需要人工确认。
5. 4:30–5:30：在对比度问题上提交不合适颜色，展示验证失败、原版本保留与失败记录。确保录制前实测该流程。
6. 5:30–6:30：打开报告，说明代码差异、证据、人工复核项与版本恢复；导出源码和报告 ZIP。
7. 6:30–7:30：介绍隔离渲染、结构化补丁与风险边界，强调自动检测并不能覆盖全部无障碍问题。

只展示实际运行得到的数据。无真实模型密钥时，展示手工审核流程并明确说明模型尚未接入。
