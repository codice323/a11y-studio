# V2.6 自动探索与检测

在诊断工作台打开项目后，点击「自动探索与检测」。进度条显示当前路径、已发现页面、已探索状态和已检测状态。停止任务后，已写入的浏览器证据仍可在当前版本的「结果报告 → 自动探索记录」查看。

## 数据与流程

1. 项目授权由账号会话及项目所有权校验。创建任务时固定当前快照。任务、证据截图和报告复用已有授权链路。
2. 静态 ZIP 枚举真实本地 HTML 文件，React 源码工程从入口开始发现同源导航。候选来自 Chromium 无障碍树和 DOM，并根据角色、精确名称、可见性、唯一性和交互契约筛选。
3. 每次尝试都在新的隔离浏览器上下文中重放路径。候选执行前重新检查定位与授权范围。指纹使用结构位置、主要语义状态和键盘焦点，忽略表单输入值和不稳定 ID。一个页面可包含多个状态。重复状态保留操作边和本次行为证据。
4. 新状态运行 axe-core 和现有行为检测，保存 DOM、Chromium 无障碍语义、资源加载信息和截图。axe 确定性违规、axe incomplete、V2.4 确认的行为异常、观测和待人工复核分别显示。
5. 状态图保存在项目级任务结果中。节点通过状态 ID、页面 ID、快照 ID 与已有状态证据关联。取消或超时保留已完成证据。报告展示选中版本最新一轮探索；先前状态证据仍按原权限访问。
6. 报告中的问题可跳至现有诊断工作台。有精确源码定位的原生按钮名称问题可复用 Agent 或人工输入、补丁审核、构建与同路径验证。候选版本如果不能重放、出现新确定性问题或关键回归，拒绝保存。动态焦点、ARIA 行为及其他动态问题仍需人工定位源码。

## 安全与预算

| 约束 | 正式账号 | 游客 |
| --- | ---: | ---: |
| 页面 | 20 | 4 |
| 状态 | 60 | 8 |
| 重放动作预算（包括重复执行的前缀） | 150 | 18 |
| 导航深度 | 3 | 3 |
| 任务时间 | 300 秒 | 45 秒 |

可用 `A11Y_EXPLORER_PAGES`、`A11Y_EXPLORER_STATES`、`A11Y_EXPLORER_ACTIONS`、`A11Y_EXPLORER_DEPTH` 和 `A11Y_EXPLORER_TIME_MS` 下调上限。单条交互路径最长 6 步，每项目最多 1 个活动探索任务，服务最多 2 个探索任务，每任务同时仅运行一个浏览器上下文。扫描器有限的键盘探测属于检测成本，不计入探索重放动作。

- 浏览器只能访问本地隔离副本，外部网络、非 GET 请求、弹窗、下载和真实表单提交被阻止。每上下文最多放行 1200 个请求。不会访问真实账号、支付、删除或上传入口。
- HTML、ZIP、静态或渲染 URL 快照仅浏览实际已保存的页面和可用原生交互。探索时不重新访问原站。授权的 React 源码工程在现有隔离构建流程中运行浏览器脚本。
- 优先处理同源链接、原生折叠、带语义契约的菜单/弹窗/标签。表单调用原生校验且不执行提交，文本只使用固定测试值。未知按钮、歧义目标、复杂选择器交互、任意远程 JS、登录后流程和读屏实际播报不在自动覆盖范围。
- 本版使用确定性规划，不向 DeepSeek 发送探索数据。既有 AI 修复仍由用户发起。未接入可选 AI 排序。

## 复现

```sh
npm run typecheck
npm run build
npm test
A11Y_EXPLORER_EVIDENCE=/tmp/a11y-v26-evidence \
  node --import tsx --test tests/explorer-policy.test.ts tests/explorer-e2e.test.ts
```

Chrome 默认使用 Mac 上安装的 Google Chrome，可通过 `CHROME_PATH` 指定。浏览器用例创建独立 SQLite 和临时 HTTP 端口。测试源有校园 ZIP、独立 React 三路由项目和单独的原生 HTML 折叠留出项目。测试中的按钮名称由审核人输入，扫描、补丁、重建与重放均走真实产品，测试不会调用付费模型。
