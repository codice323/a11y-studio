# 测试与验收

`npm run test` 使用临时数据库、隔离文件目录和本地模拟模型接口，执行三个示例的真实 Playwright/axe 扫描；对表单、图片、按钮执行审核和文件级修复；验证原始文件未覆盖、无新增问题及版本记录；测试低对比度修复失败时回滚；测试 ZIP 导入、非法文件拒绝、源码与报告导出；扫描工作台自身的严重无障碍问题。`npm run typecheck` 检查 TypeScript。

进一步人工检查：使用真实模型与测试密钥核对建议质量和额度不足行为；针对屏幕阅读器、键盘导航和缩放运行人工检查；使用更多复杂静态项目核对截图、样式和文件路径；用真实授权数据进行对比实验并记录指标。

当前回归检查是结构、文本、交互属性、控件聚焦和目标规则的检查，不执行用户脚本，也不能证明复杂业务流程无回归。不得将自动检测通过或模拟模型结果视为完全合规或真实模型修复成功率。

URL 导入单元测试使用受控 DNS 和 HTTP 响应，覆盖地址分类、DNS 混合地址、重定向校验、资源限制、同源资源、静态清理和大小上限。产品端到端测试使用本机 HTTP 样站，经测试进程专用转发接入已校验的固定测试地址。扫描、补丁、复测、Chromium 语义、截图、回滚和导出使用真实服务与 Chromium。

运行产品端到端测试前先执行 `npm run build`，确保本机允许测试进程绑定回环端口，且已安装 Chrome 或设置 `CHROME_PATH`。另外可在具备公网 DNS 与出站连接的环境，从首页选择 URL，输入一条有权限检测且已知存在无障碍问题的公开网页，验证公网连接、扫描、修复和导出全流程。

## 检测引擎 V2

Playwright 通过 `@axe-core/playwright` 4.13.0 注入其自带的 axe-core 4.13.0。顶层安装的 axe-core 4.14.0 并非现行扫描器的注入版本。旧版标签是 `wcag2a`、`wcag2aa`、`wcag21a`、`wcag21aa`、`wcag22aa`。V2 额外选用 `wcag22a` 和 `best-practice`，禁用 `focus-order-semantics`、`hidden-content` 两个实验性最佳实践。当前实际规则清单中 `wcag22a` 没有规则，因此这一标签本身没有增加 WCAG 检查。V2 增加的规则证据主要来自非实验性最佳实践，另行展示于 API 和 JSON 导出。

使用真实 Chromium 测试，样页和人工标注位于 `tests/fixtures/detection/`：

```sh
node --import tsx --test tests/detection-benchmark.test.ts
```

- **准确性与精确率**。若讨论分类准确率，分母是全部正负标注，公式为 (TP+TN)/(TP+TN+FP+FN)。精确率 Precision 是被标出的项目中确实有问题的比例，即 TP/(TP+FP)。
- **召回率 Recall**。人工已标出的真实问题中被系统捕获的比例，即 TP/(TP+FN)。
- **自动化覆盖率**。约定的标准、组件及状态中可自动判定的比例。必须先定义规则或检查项全集及判定条件，不能用本样页的召回率、axe 规则数或人工复核比例替代。
- **评分口径**。比较旧规则与 V2，两组分别计算确定性 WCAG 违规和含建议的筛查结果。以目标选择器与标注规则集匹配，一条标注最多计一次。显式负样本被标出计 FP，显式正样本未标出计 FN。未标注输出不计分。人工复核比例是只由待复核信号匹配的标注数除以全部匹配标注数，零分母返回 null。AI 三条语义标注列入语料但不参与该次评分。
- **计时与范围**。记录规则时间和 V2 新增浏览器行为时间。V2 行为时间包含重载以重置键盘起点。初次加载、截图和存储不进入对比。样页用于回归和口径核对，公开站点代表性、屏幕阅读器兼容性和生产性能需要额外评测。

行为测试通过真实 Tab、计算样式及 Chromium 无障碍树收集证据。脚本、框架和外部网络继续受原有隔离约束，未按 Enter/Space 触发导航或业务动作。Tab、候选数和时长有限制。正 tabindex、未到达、样式未变化及 ARIA 状态不一致要求复核。样式变化本身也不能证明焦点可见。动态组件需要未来单独设计隔离执行与交互测试。
