# 深度交互检测 V2.4

本轮沿用版本化操作记录与重放。起点是账号 V1.3 的 `6d326d5`。每个已采集状态仍绑定项目、版本、页面及操作配方，使用原有访问控制和存储。重放过程中额外读取操作前后的浏览器状态，先记录路径和焦点，再对最终 DOM 执行 axe 和有限 Tab 探查。历史记录没有新证据时可重新采集，现有数据无需迁移。

## WCAG 2.2 A/AA 覆盖

Playwright 1.65.0 的 `@axe-core/playwright` 4.13.0 实际向 Chrome 注入 axe-core 4.13.0。根依赖的 axe-core 4.14.0 不是这条扫描路径注入的版本。启用 `wcag2a`、`wcag2aa`、`wcag21a`、`wcag21aa`、`wcag22a`、`wcag22aa` 和 `best-practice`，排除 `focus-order-semantics`、`hidden-content`。安装版本有 98 条配置匹配规则，其中 70 条带 WCAG 标签，28 条仅作为最佳实践分类。规则标签表示检测涉及的条款，不能作为条款完整覆盖率。

|---|---|---|
| 非文本内容 1.1.1 | 已渲染图片、SVG、图片按钮等的名称或替代文本检查 | 图片用途、替代文本质量由人工或可选 AI 复核 |
| 媒体 1.2.1–1.2.5 | 已渲染媒体的部分轨道检查；实时报告记录轨道证据 | 内容完整性、字幕同步和准确性、音频描述需人工 |

| 其余 A/AA 场景 | 未建立完整自动判定 | 闪烁风险、跨页面一致性、复杂时限等由人工逐项验证 |

在本机生产库只读抽样中，150 条已完成入口审计的确定性结果集中在 6 条规则，分别是 label 125、button-name 118、color-contrast 108、link-name 107、image-alt 83、target-size 21。这些计数包含重复版本与复测。不能由此推断站点缺陷比例。新旧规则均区分违规、incomplete 和最佳实践，且规则会因当前 DOM 不适用而返回 inapplicable。入口审计与全站重放报告是不同查询范围，隐藏或未执行的状态不会进入入口结果。

## 动态证据和安全边界

- 现有源码工程内的安全导航、菜单、标签、弹窗、固定文本输入、原生校验与键盘步骤均可作为证据。静态快照仍限制原始脚本运行。外部网络、真实表单提交与敏感输入继续受现有隔离策略约束。
- 已确认行为异常独立于 axe 确定性 WCAG 违规。修复验证重放同一配方，拒绝新增已确认异常。模态焦点返回、重复 Tab、aria-expanded、校验关联和路由上下文保留复核分类。实时区域变化只证明 DOM 更新。无自动源码策略的行为证据不会生成补丁；同状态的 axe 问题仍走原有审核与复测。
- 工作台只显示所选版本、页面和状态的证据。结果报告保存操作前后路径与焦点、规则及级别。报告不保存输入值或实时区域原文。
- 交互按现有配方与时间预算执行。未触发的状态、未知路由、复杂登录与业务流程、跨域 iframe、辅助技术播报、完整键盘陷阱和触屏体验尚未自动覆盖。截图、操作观测与自动违规是独立证据。
- 实时双侧浏览继续使用其自身的即时观察；本轮新增的分类和回归判定用于已保存、可重放的状态。人工改动 Tab 路径时，原有严格匹配仍可能要求人工验证。

## 复现

```sh
npm run typecheck
npm run build
npm test
npm run test:campus
A11Y_PANORAMA_EVIDENCE=/path/to/local-evidence node --import tsx --test tests/interaction-audit.test.ts tests/panorama-e2e.test.ts
```

在 macOS 使用系统 Chrome，或通过 `CHROME_PATH` 指定 Chromium。测试创建独立临时项目和数据库。浏览器轨迹仅用于测试账号与测试数据，按私有调试文件保存。

## Mac 验收记录

- 系统 Chrome 157.0.8103.39 下，类型检查、生产构建、35 项回归和校园端到端专项均通过。全量回归耗时约 176 秒，校园专项约 158 秒。这些是测试总耗时，不能用于估算单站扫描性能。
- 独立静态工程与 React 工程各验证两个页面，分别保存八个和七个状态。同状态按钮修复及复测通过，共享样式回归和跨版本控件失配被拦截。
- 八个新标注样例针对模态打开时的焦点异常。单独运行 axe 检出 0/2，增强后为 2 TP、0 FP、0 FN、6 TN。另用真实 Tab 验证了焦点逃逸。小样本只用于校验这两类行为，不能外推至全站。
- 校园专项覆盖 HTML、ZIP、源码工程和两种 URL 模式，验证导入、浏览、补丁、复测、失败回退及离线导出。AI 端点使用本地 Mock，未调用真实 DeepSeek。
