# V2.5.2 网页交互对比

网页交互对比沿用现有路由和检测服务。默认工具栏显示版本选择、交换版本、同步、更多操作和退出。「更多操作」收纳手动检测、重新获取画面、记录下载和页面信息。静态导入不运行原站脚本，适用范围在页面信息中说明。操作记录默认折叠，按时间记录本次对比中的操作、同步结果、路径与检测摘要。

V2.5.1 在每一笔动作请求开始和结束时改变可见 loading 状态及多个按钮的禁用属性。V2.5.2 使用内部锁维持动作顺序，普通点击和滚动不再更新 loading。预览图片在新帧解码后替换。连接、主动检测和获取证据使用不参与布局的状态通知，失败提示位于预览下方。旧画面上的坐标点击未执行时，提示重新点击；页面已变化时自动获取新画面，避免误点。

## Chrome 对照实测

Chrome 157.0.8103.39，1440×1000 浏览器窗口。两次测试使用相同的 React 工程、路由、版本以及 40 次 12px 滚轮输入。状态出现帧和预览位置按动画帧采样；工具栏 DOM 变化由 MutationObserver 计数。

| 指标 | V2.5.1 | V2.5.2 |
|---|---:|---:|
| 采样到显示常规加载提示的帧 | 26 | 0 |
| 工具栏 DOM 变化次数 | 152 | 0 |
| 工具栏高度 | 73.6px | 59.6px |
| 预览纵向位置波动 | 0px | 0px |
| 预览图片不可用或换节点的采样帧 | 0 | 0 |
| 两侧实际滚动距离 | 480px | 480px |
| 滚动请求数 | 19 | 19 |
| 生成 / 传输截图数 | 38 / 22 | 38 / 22 |
| 首帧更新延迟 | 76.7ms | 80.7ms |

首帧延迟从首次 wheel 到第一张更新图片解码计算。数据为一次同条件对照，不能由 4ms 差值推断稳定的速度变化。另做 160 次滚轮输入，包含左侧发起与右侧发起，两侧最终均回到 480px，未采样到不可用画面。

过期专项使用原有五分钟服务端计时。键盘验收覆盖展开、收起操作记录与恢复入口，重要失败信息使用 Chrome 无障碍树校验警报语义。真实浏览器运行在隔离测试项目中，测试 Agent 使用本地模拟服务。

Mac 本地已通过类型检查、生产构建、35 项回归、左右连续滚动专项，以及真实五分钟会话过期后的键盘恢复。验收还覆盖版本切换、同步失配、滚动在途点击保护、动态检测和补丁验证。已检查 Chrome 无障碍树中的警报语义，未运行 macOS VoiceOver 实机播报。
