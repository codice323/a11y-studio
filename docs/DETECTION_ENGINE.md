# V2 检测引擎

V2 在隔离的静态快照上运行 axe-core，再用真实 Tab 按键、浏览器计算样式和 Chromium 无障碍树采集行为证据。网页原有脚本不会执行，扫描期间禁止外部网络请求。默认 `npm start` 使用与测试相同的 TypeScript 运行方式。

| 输出 | 用途 |
| --- | --- |
| `issues`、`detection.violations` | 确定性自动检测违规，用于待处理列表、补丁和复测 |
| `detection.incomplete`、`detection.bestPractices` | axe 不确定项和最佳实践，供人工判断 |
| `detection.behavior.findings` | 浏览器观测和启发式待复核提示 |
| `detection.ai.findings` | 经同意调用模型得到的疑似结果及人工决定 |

工作台和结果报告分别显示行为证据与确定违规。旧扫描缺少 `detection` 时仍可查看和修复。完整检测对象保存在导出 ZIP 的 `report/report.json`。AI 修复建议以确定违规为入口，继续使用现有审核流程。AI 辅助复核通过单独的 API 发起，可查看已保存的结果。[API 字段与复核接口](API.md)

行为检测记录实际 Tab 顺序。正 `tabindex` 引起的实测逆序和控件可能无法经 Tab 到达都归入待复核。焦点判定比较控件、伪元素及最多四层近邻祖先的计算样式，忽略透明轮廓、边框和阴影。兄弟节点提供的提示、被裁切的焦点轮廓、复杂布局与动态交互需要额外验证。行为阶段可能报告部分完成或不可用。此时规则证据仍可使用。

## 验证

在同一台 Mac、Chrome 157.0.8103.39 和实际注入的 axe-core 4.13.0 下，对 V1 `01ca0d0` 和已验证的 V2 引擎快照 `3a1c949` 进行三轮对照。31 个固定页面在每轮各扫描一次。

| 辅助筛查 | TP / FP / FN | Precision | Recall | F1 | 平均耗时 |
| --- | ---: | ---: | ---: | ---: | ---: |
| V1 | 18 / 0 / 27 | 100.0% | 40.0% | 57.1% | 588.3 ms |
| V2 | 36 / 0 / 9 | 100.0% | 80.0% | 88.9% | 610.2 ms |

确定性违规计分与 V1 一致。冻结补丁后制作的 10 个独立页面结果为 4 TP、1 FP、1 FN、4 TN。基准结果适用于这些静态样例。产品集成复用已测引擎，额外测试证据展示、工作台双栏、HTML / ZIP / URL 导入、补丁审核、复测、回滚和导出。模型接口测试使用本地模拟供应商。
