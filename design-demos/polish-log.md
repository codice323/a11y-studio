# 打磨记录

## 初稿审阅

- 发现：直接把工具做成纯白极简会让用户误以为页面没加载；已在方向 A 保留现有浅蓝灰画布和清楚的卡片边界。
- 发现：小缩略图不利于视障议题的人工核验；完整版将网页证据作为主要视觉区域，并提供 before/after 切换或并排放大。
- 发现：代码差异容易挤压证据面积；完整版默认展示人类可读的影响说明，开发者证据折叠。
- 发现：测试截图若来自真实登录页面会泄露私人内容；统一采用虚构活动报名页面。
- 发现：单列放大模式更适合检查局部文字和表单；补上单列切换并在 375px 检查堆叠顺序。
- 发现：对比度展示值要和实际 CSS 颜色一致；把演示颜色校准到 2.81:1 与 7.11:1。
- 修正：深色巡检方向初稿将证据区压成窄列；调整为主证据区 + 右侧问题队列。
- 检查：三份完整稿在 1440px 查看，主方向额外在 375px 查看；问题切换和单列放大可用，浏览器控制台无错误。
- 限制：随附 `design_lint.py` 因当前环境没有 Python Playwright 而跳过；页面已用本机 Chrome 实际打开并人工查看。
