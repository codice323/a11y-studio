# A11y Studio UI 方向预览

打开 `directions.html` 查看六个缩略提案，再点开 A、B 或 C 查看完整工作台原型。各页面引用同目录下的 `workbench.css` 和 `workbench.js`，可直接用浏览器打开，也可访问本地预览 `http://127.0.0.1:4180/directions.html`。
